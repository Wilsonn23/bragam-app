# PB07 dan PB08: integrasi dan batas verifikasi

## Data dan integrasi

Dataset produksi `src/poi/adapter.js` masih kosong. Backend hanya menyediakan `/health`; tidak ditemukan 12 POI, foto destinasi, naskah, audio, ulasan, atau dokumen PRD/UI05 di repositori. Fixture `tests/fixtures/pois.js` sintetis dan hanya untuk development. Tim PB03 perlu mengisi `pois` dengan hasil `adaptPois` dari sumber tervalidasi, dengan ID unik stabil sesuai kontrak PB05-PB06. Adapter mempertahankan field tambahan. UI detail membaca `description`, `openingHours`, `menu`, dan `reviews` sebagai teks opsional serta `imageUrl` dan `audioUrl` sebagai URL; `audioUrl` harus HTTPS dan merujuk rekaman berlisensi yang telah diverifikasi. Field kosong ditampilkan sebagai belum tersedia. Bentuk ini merupakan kontrak sementara, bukan klaim bahwa data sudah ada; sesuaikan adapter ketika skema PB03 disepakati. Foto yang gagal punya fallback.

PB04/search dapat membuka `router.push({ pathname: '/poi/[id]', params: { id: poiId } })`; modal PB06 menggunakan callback yang sama. Mode simulasi menambahkan `simulation: '1'` dan hanya membaca fixture pada build development. Jangan gunakan parameter itu untuk data produksi. UI mengikuti tema yang ada karena UI05 tidak tersedia untuk dicocokkan. Rating dan ulasan hanya dibaca sebagai teks yang telah disediakan, tidak ada pembuatan ulasan.

Player tunggal berada pada layout akar agar terus hidup saat kembali dari detail. Saat narasi POI lain diputar, player lama dijeda dan sumber diganti. `expo-audio` dikonfigurasi untuk background dan kontrol media; perubahan konfigurasi native memerlukan binary baru. Aset/audio dan jaringan dapat gagal; pesan kesalahan disediakan. Pemutaran, sesi media, dan perilaku saat gangguan OS tetap harus diuji pada perangkat.

## Checklist perangkat (belum dilaksanakan)

1. Isi dataset kurasi dengan setidaknya 12 rekaman, foto dan URL audio yang sah; periksa izin/lisensi, keakuratan dan seluruh fallback.
2. Buat build Android dan iOS baru dengan config plugin audio; buka detail tiap ID melalui peta dan trigger, coba ID tidak valid dan URL gambar/audio yang rusak. Periksa VoiceOver/TalkBack, ukuran teks besar, tombol kembali dan layar kecil.
3. Putar dan jeda audio masing-masing POI; kembali ke eksplorasi, lalu putar POI lain dan pastikan tidak ada dua sumber bersamaan. Uji gangguan telepon/audio lain, koneksi hilang, headphone dilepas dan dibuka ulang.
4. Kunci layar atau pindahkan aplikasi ke background selama lebih dari tiga menit; verifikasi suara dan kontrol media Android/iOS. Uji tombol fisik headset play/pause pada kedua platform, termasuk saat layar terkunci, dan amati status setelah kembali. Catat model, versi OS, hasil dan log.

Referensi SDK: https://docs.expo.dev/versions/v58.0.0/sdk/audio/ dan https://docs.expo.dev/router/installation/. Export JS, lint atau unit test bukan bukti pengujian native, media session, headset, atau lapangan.
