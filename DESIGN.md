# BRAGAm mobile

Indonesian product UI for visitors exploring Jalan Braga. The current Home/Explore/tab implementation is the visual reference, replacing the earlier GPS-only demo. Runtime tokens live in `mobile/src/components/theme.js`: darkPurple #35166F, primaryPurple #5B2BBF, lavenderTint #EAE2F8, softLilacBg #F9F7FD, white #FFFFFF, textPrimary #311465, textSecondary #6B5894. The `theme` export is a compatibility adapter to these same tokens for Router detail and shared feedback controls, not a second palette.

UI04 now follows the accessible Figma copy `5MJzy7VlHWVrTYky8yR0sI` / `5:1983` (context and screenshot read 2026-11-14). Notification-only tokens are exported as `POI_NOTIFICATION`: surface #F9F7FF, border #602ECC, ink #3A1678, backdrop rgba(34,24,51,0.5), radius 32, border 4. Other screens keep their existing palette. UI04 uses locally bundled Plus Jakarta Sans regular/medium/semibold/bold from the Expo Google Fonts package, with system fallback if loading fails.

The card has a centered dynamic heading, three horizontally scrollable photo slots, pin/name/category and a computed distance when supplied, description summary, secondary action row, then side-by-side Cek Sekarang / Gak dulu deh. Actual SVGs from the Figma popup are stored unchanged in mobile/assets/pb06; their source layers/dimensions are recorded in its README. No fabricated rating or 12km sample distance. Body/category remain present as required by the data contract even though absent from the screenshot. Directions uses the existing route flow; Save/itinerary are visibly disabled until those features have real handlers. Primary actions stay outside the body scroller for long text. Buttons are at least 48 points high (the reference uses 38); rows wrap on small screens. Gallery root SVG sizes remain intrinsic and can be scrolled horizontally rather than distorted.

Canonical modal host: PoiTriggerModal; card: PoiNotificationCard. It retains one native Modal, safe areas and Android back dismissal across queue changes. The previous file's access denial is historical; the copy is now the visual reference. Browser verification uses the actual card through an isolated React Native Web harness with local SVG/font adapters, not the full app or a native device. Native rendering and exact device correspondence remain unverified.

Existing map, navigation, trip, detail and audio screens are retained. The Router detail route renders main's `PoiDetailScreen` (Overview/Menu/Review/About) with the provider's selected POI and the existing AudioProvider. The former generic GPS-era detail is no longer the presentation owner. Detail Directions uses the existing NavigationScreen through `/navigation/[id]`, preserving the POI's API coordinates. Native rendering, small screens, dynamic text, safe areas and accessibility still need device checks. Behavior contract: UX-CONTRACT.md.

Explore follows `origin/main` at `a877949`: its map palette, search bar, sheet heights, segments, filters, card carousel, shared footer styles and bottom navigation remain the visual reference. Successful GPS/API operation adds no status panel before the cards. Loading, failure/retry and empty states appear only when needed. There are no simulation controls, development panels or hidden bookmark gestures in any app build. API records and device GPS are the only runtime sources; synthetic POIs exist exclusively under tests. Main's sample distances/ratings are not used as real data.

## PB12 Explore Recommendation (current surface)

Reference: Figma file `5MJzy7VlHWVrTYky8yR0sI`, node `5:1242`, inspected 17 November 2026. The composed screen is Explore's existing map and bottom sheet, not a new navigation destination. The reference's lavender dividers, horizontal photo strip, two-segment selector and rounded purple actions are its identifying structure. Existing Explore, tab bar, photo gallery and `PoiDetailFooter` remain the owners; the footer's `recommendation` variant wraps for small screens and long labels.

Runtime tokens remain canonical (Model B): `mobile/src/components/theme.js` owns `COLORS.primaryPurple` (#5B2BBF), `darkPurple` (#35166F), `softLilacBg` (#F9F7FD), `lavenderTint` (#EAE2F8), text and border roles, and `RADIUS`. PB12 reuses this shared palette rather than changing sibling screens. `RecommendationPanel` owns its list/filter/status layout; `PoiFilterPicker` owns the new accessible native-modal picker. Plus Jakarta Sans, used by the Figma reference, is bundled locally under `mobile/assets/fonts` with its OFL license; `App` loads it as `PB12Jakarta`, and PB12 text/inputs and the recommendation footer use that family. Other screens retain their typography.

The reference's crossed photos are placeholders, not assets to repeat in production. Dynamic `imageUrl`/`images` from the POI contract flow into `PoiImageGallery`; absent or failed images display a labelled lavender fallback with reserved geometry. Existing vector icon families supply the shared pin, stars, directions, bookmark, plus and chevron. Native Maps supplies the map background. No Figma screenshot or temporary asset URL is used in application code.

Controls have at least 44-point action height and grow with text. Recommendation owns one vertical FlatList, with horizontal gallery/filter scrollers. Its sheet height is bounded by the actual content viewport so the existing bottom navigation remains reachable; keyboard shrink is applied within this panel. The already-present sheet expansion/drag behavior is reused. Product labels retained from the English Figma design coexist with Indonesian recovery messages, matching the current app's vocabulary. System font fallback is used if local font loading fails; native font scaling, safe areas and map rendering still require device checks.
