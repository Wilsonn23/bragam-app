# BRAGAm mobile

Indonesian product UI for visitors exploring Jalan Braga. The current Home/Explore/tab implementation is the visual reference, replacing the earlier GPS-only demo. Runtime tokens live in `mobile/src/components/theme.js`: darkPurple #35166F, primaryPurple #5B2BBF, lavenderTint #EAE2F8, softLilacBg #F9F7FD, white #FFFFFF, textPrimary #311465, textSecondary #6B5894. The `theme` export is a compatibility adapter to these same tokens for Router detail and shared feedback controls, not a second palette.

UI04 now follows the accessible Figma copy `5MJzy7VlHWVrTYky8yR0sI` / `5:1983` (context and screenshot read 2026-11-14). Notification-only tokens are exported as `POI_NOTIFICATION`: surface #F9F7FF, border #602ECC, ink #3A1678, backdrop rgba(34,24,51,0.5), radius 32, border 4. Other screens keep their existing palette. UI04 uses locally bundled Plus Jakarta Sans regular/medium/semibold/bold from the Expo Google Fonts package, with system fallback if loading fails.

The card has a centered dynamic heading, three horizontally scrollable photo slots, pin/name/category and a computed distance when supplied, description summary, secondary action row, then side-by-side Cek Sekarang / Gak dulu deh. Actual SVGs from the Figma popup are stored unchanged in mobile/assets/pb06; their source layers/dimensions are recorded in its README. No fabricated rating or 12km sample distance. Body/category remain present as required by the data contract even though absent from the screenshot. Directions uses the existing route flow; Save/itinerary are visibly disabled until those features have real handlers. Primary actions stay outside the body scroller for long text. Buttons are at least 48 points high (the reference uses 38); rows wrap on small screens. Gallery root SVG sizes remain intrinsic and can be scrolled horizontally rather than distorted.

Canonical modal host: PoiTriggerModal; card: PoiNotificationCard. It retains one native Modal, safe areas and Android back dismissal across queue changes. The previous file's access denial is historical; the copy is now the visual reference. Browser verification uses the actual card through an isolated React Native Web harness with local SVG/font adapters, not the full app or a native device. Native rendering and exact device correspondence remain unverified.

Existing map, navigation, trip, detail and audio screens are retained. PB05–PB06 integrates the existing Router detail without rebuilding UI05/audio. Native rendering, small screens, dynamic text, safe areas and accessibility still need device checks. Behavior contract: UX-CONTRACT.md.

Explore follows `origin/main` at `a877949`: its map palette, search bar, sheet heights, segments, filters, card carousel, shared footer styles and bottom navigation remain the visual reference. Successful GPS/API operation adds no status panel before the cards. Loading, failure/retry and empty states appear only when needed. Development controls are hidden by default and opened by long-pressing the existing bookmark icon in development builds; closing the panel also leaves simulation. Real API records and the shared GPS subscription remain authoritative; main's sample distances/ratings are not used as real data.
